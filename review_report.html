FPL AI Project — Review Report
Fantasy Premier League Team Optimisation Using ML and Linear Programming

1. What Are We Building?

An AI system that looks at 5 years of Fantasy Premier League player data and answers two questions:

  1. Prediction: How many FPL points will each player score next season?
  2. Selection: Given those predictions, which 15 players should I pick within a £100m budget?
Think of it like this: Instead of manually guessing which players to pick, the AI analyses historical patterns and automatically picks the best possible squad.

2. Data

All data was fetched from the official FPL API. We collected 5 seasons of data (2021/22 to 2025/26) covering ~700 players per season.

5. Models

5.1 XGBoost

XGBoost is a powerful gradient boosting algorithm that builds many decision trees sequentially, each correcting the errors of the previous one. It works very well on structured tabular data like ours.

8. Summary

The pipeline works end to end:

  1. ✅ Data fetched from FPL API — 5 seasons, 700+ players
  2. ✅ 24 features engineered including lag features and xG metrics
  3. ✅ XGBoost trained — R²=0.300, MAE=35.5 pts
  4. ✅ Neural Network trained — R²=0.305, MAE=36.5 pts
  5. ✅ Ensemble predictions computed
  6. ✅ ILP optimiser selects valid £100m squad
  7. ✅ Optimal squad correctly identifies top performers

Why R² is 0.30 and not higher

Football is inherently unpredictable. Players get injured, managers change tactics, and form fluctuates week to week. An R² of 0.30 is consistent with published results in sports prediction literature. The key strength of our system is not perfect prediction — it is systematic, data-driven selection that outperforms random guessing.
